    • How to configure EstudiPro for the first time

    EsudiPro is very easy to configure. If you have never accessed EstudiPro before, now we will teach you how to configure its style:

    1. On the main screen, access the configuration button.
    2. In the background section, there are two color selectors: the first is to select the start of the gradient and the second the end of it. Select the colors you like the most or leave them as they are by default (#FAFAFA).
    3. Expand the font section, and select the one you prefer. The default is Montserrat, since it is a font that is pleasant to the eye and easy to read, which is very good for these cases.
    4. Now you can save the settings and every time you enter EstudiPro you will see these style settings.

    How to use EstudiPro?

    To start using EstudiPro, type in the input that you can see what you will be doing during the time you will be working. Also select one of the preset times that we offer or choose the time yourself with the number selector. Click start and you can start working.


    When the time is up, the counter will start counting with a + in front, indicating the time you have been doing more than you had planned. The time that appears in the history that you can see to the right or below the timer is the total time. You can download this history by clicking "Export CSV".


    How do I get back to the start?

    If you want to return to the EstudiPro home page (where the stopwatch, history and settings are) all you have to do is click on the website title.


    What should I do if I find a screen adaptation error?

    If you find a screen adaptation error on smaller screens, such as some part not appearing or not being seen as it should be, what you have to do is send us an email to arnautm-dev@proton.me. In this email, include a short description of the problem, some screenshots or photos of the problem and your contact details. We will try to solve it as soon as possible, and then we will contact you to inform you that the error has been resolved.


    The button does nothing when I click it

    If a button does not work within our platform, there are two possibilities: an internal error or an error in the user's device or browser. First of all, try refreshing the page or restarting your device. This sometimes makes the buttons work. If they do not, send us an email (arnautm-dev@proton.me) informing us of the problem. We will see if it is our error or the user's.
